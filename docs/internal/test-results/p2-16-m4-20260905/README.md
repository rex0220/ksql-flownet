## 結果(全項目 OK)

| 受入 | 内容 | 結果 |
| --- | --- | --- |

## 受入中のフィードバックと修正(3 件・すべて表示)

1. START要求の理由列が狭く 1 文字ずつ折り返す → `min-width: 12em` と単語単位の折り返し(v3)
2. 終端 Run の hold が見えない(CLI で作った hold は要求レコードが無い)→ 「停止hold」バッジ+補足行(v4)
3. 操作列の pending 表示が 1 行 nowrap で他列を潰す → 2 行ブロック(見出し/起票者・理由)+操作列の上限幅 18em(v5)
