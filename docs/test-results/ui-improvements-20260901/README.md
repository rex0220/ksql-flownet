# ボード/プラグインUI改良シリーズ 記録(2026-09-01)

- ブランチ: ui/board-polish(9巡、plugin v6→リリース版v1へ再番号)→ main d94c7a2
- 方式: ユーザーの実機フィードバック駆動(スクリーンショット→修正→再確認の反復)。単体419件合格を維持

## 改良内容(確定)

- ボード: ヘッダーツールバー(判定時刻+再読込)/セクションカード+件数バッジ/日本語列名・ローカル時刻表示/操作ボタンの1行固定・位置統一/平易なセクション名(進行中のRun・終了済み・対応が必要なRun)/エラー概要列(分類)+エラー本文の全幅サブ行/レコード番号の別タブリンク
- ダイアログ・設定画面: FlowNetロゴ+ヘッダー帯・定義リスト・情報ボックス・コールアウト・フッター右寄せボタン、設定は入力短縮+横注釈+sticky保存
- 機能: 関連レコード3種(JOBログ=run_id↔correlation_id、監査・操作要求=run_id↔run_id)テンプレート`add-run-related-lists.console.js`/プラグインのゼロコンフィグ(関連定義から3アプリ自動検出+検出表示+アプリ名プレビュー)/保存時に運用環境へ反映(deployOnSave、参考: ksql-dashboard-proの実績パターン)
- 配布方針: リリース配布は複数アプリ一括のkintoneアプリテンプレートを正とする(インポート時のアプリ間参照張替えで自動検出がそのまま機能)。Consoleスクリプトは追補・開発用

## 実機で検出した不具合(修正・回帰固定済み)

- REFERENCE_TABLEは追加時に自動レイアウト配置(明示追記は重複エラー)/未デプロイ中断からの再開対応
- 長文エラーを1セルへ入れると表全体が崩れる→サブ行方式へ
- SHA-256系3フィールドがレイアウト幅調整の対象外だった→追加
