Run状況 設定

入力欄が空の場合は、下記の関連レコード一覧から自動検出したアプリを使用します。自動検出先を上書きしたい場合のみアプリIDを入力してください。

VPSのallowlistでapp_start: trueを設定したネットワークを「ネットワーク名, network_id[, 入力モード[, business_keyテンプレート]]」のCSV形式で1行ずつ入力します。

設定のバックアップ（ダウンロード／アップロード）

ダウンロード: 現在の設定を JSON で保存。アップロード: 選んだ JSON で現在の設定を置き換え（反映するには「保存」してください）。
